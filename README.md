# 📊 Calculadora de Bounty Power para PKO/KO

Uma ferramenta simples, rápida e precisa para calcular a equidade mínima necessária ao enfrentar situações de call em torneios com bounty progressivo (PKO/KO).

Desenvolvida com **Python + Streamlit**, a calculadora permite:

- Converter bounty em fichas com base no stack inicial ou médio
- Calcular o pot final estimado
- Determinar a equidade mínima necessária para um call lucrativo
- Receber sugestão automática de **CALL** ou **FOLD**, com base na sua equidade estimada

---

## 🧠 Por que usar?

Em torneios KO/PKO, o bounty influencia diretamente a decisão de dar call ou não. Esta calculadora ajuda a:

- Evitar erros matemáticos em decisões críticas
- Tomar decisões mais lucrativas baseadas em valor esperado (EV+)
- Agilizar o processo de cálculo durante o jogo

---

## 💻 Como rodar localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/bounty-power-calculator.git
cd bounty-power-calculator
```
2. Instale as dependências:

```bash
pip install streamlit
```
3. Execute o app:

```bash
streamlit run bounty_calculator_app.py
```
